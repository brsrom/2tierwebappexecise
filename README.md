# 2tierwebappexecise

Terraform-managed Azure lab environment: a VNet with a public subnet (legacy MongoDB VM) and a
private subnet (AKS cluster), an Azure Container Registry, and the `todoapp` deployment under
[`app/todoapp/`](app/todoapp/).

## Remote state

State is stored in the `tfstate` container of the `st2tiermongobkpjhe3h7` storage account (same
account used for MongoDB backups — reused rather than provisioning a dedicated one). Auth is via
the storage account key, passed as the `ARM_ACCESS_KEY` environment variable — never committed or
stored as a persisted secret.

To run Terraform locally:
```bash
export ARM_ACCESS_KEY=$(az storage account keys list \
  --resource-group rg-2tier-wizexercise \
  --account-name st2tiermongobkpjhe3h7 \
  --query '[0].value' -o tsv)

terraform init
terraform plan
```

## Retrieving generated secrets

The SSH private key for the MongoDB VM and the MongoDB admin credentials are generated by
Terraform but not written to disk automatically. Pull them on demand:

```bash
terraform output -raw legacy_vm_private_key_pem > key.pem && chmod 600 key.pem
terraform output -raw mongodb_admin_credentials
```

Both source resources (`tls_private_key.legacy_vm`, `random_password.mongodb_admin`) have
`lifecycle { prevent_destroy = true }` — they can't be silently regenerated by a future config
change, so these values are stable long-term. Both are also mirrored into GitHub Actions secrets
(`LEGACY_VM_SSH_PRIVATE_KEY`, `MONGODB_PASSWORD`) so workflows can use them directly without
needing backend access.

For AKS, don't store a kubeconfig at all — always fetch a fresh one:
```bash
az aks get-credentials --resource-group rg-2tier-wizexercise --name aks-2tier-wizexercise
```

## CI/CD

- **`.github/workflows/terraform.yml`** — applies the infra in this repo on every push to `dev`
  that touches root-level `*.tf`/`*.tpl` files. Full auto-apply, no manual gate.
- **`.github/workflows/deploy-todoapp.yml`** — builds, pushes, and deploys `app/todoapp/` on every
  push to `dev`/`main` touching `app/todoapp/**`. See [`app/todoapp/README.md`](app/todoapp/README.md).

Both authenticate to Azure via the same service principal (`secrets.AZURE_CREDENTIALS`).
